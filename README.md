# SQUARE::ERAUQS

> 이 저장소는 출시 관련 제약으로 공개할 수 없는 원본 비공개 저장소를 대신해 마련한 **포트폴리오용 공개 샘플 저장소**입니다. 프로젝트 소개와 담당 범위에 해당하는 핵심 코드 발췌를 제공하며, 전체 소스·에셋·개발 이력은 포함하지 않습니다. 샘플은 이해를 돕기 위해 일부 의존성을 생략하거나 재구성했으며, 각 문서에 그 범위를 명시했습니다.

## 게임 소개

SQUARE::ERAUQS는 두 캐릭터를 동시에 조작하며 시점 전환과 다양한 물리 기믹으로 퍼즐을 해결하는 2D 퍼즐 플랫포머입니다.

탑뷰와 사이드뷰를 오가며 달라지는 공간을 활용하고, 중력 전환·빙판·스프링 등의 상호작용을 조합해 길을 찾아갑니다. PC 버전의 Steam 출시를 거쳤으며, Android 이식도 완료하였습니다.
